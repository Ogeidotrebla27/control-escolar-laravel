# 🎓 Sistema de Control Escolar - Escuela Primaria Cuauhtémoc

Sistema integral de gestión escolar desarrollado con **Laravel 13** y **Tailwind CSS**, diseñado para optimizar la administración de alumnos, tutores, personal docente y la bitácora de la escuela.

## 📋 Características Principales

*   **Gestión de Alumnos:** Registro completo (datos personales, médicos, documentación y estatus).
*   **Gestión de Tutores:** Vinculación de padres y tutores con sus hijos, permitiendo múltiples alumnos por tutor.
*   **Bitácora Escolar:** Registro de conductas, felicitaciones, participaciones, atenciones a padres y eventos generales de la escuela.
*   **Listados e Impresión:** Generación de listas de alumnos y tutores (por grupo, generales o para juntas), optimizadas para imprimir en tamaño carta.
*   **Fichas de Alumno:** Impresión de fichas simples, con historial de bitácora o solo el historial.
*   **Roles y Permisos:** Control de acceso para Administradores, Directores, Docentes y Personal Administrativo.

## 🛠️ Tecnologías Utilizadas

*   **Backend:** PHP 8.5 / Laravel 13
*   **Frontend:** Tailwind CSS / Alpine.js / Blade
*   **Base de Datos:** MySQL / MariaDB
*   **Generación de PDF:** DomPDF
*   **Autenticación:** Laravel Breeze
*   **Roles y Permisos:** Spatie Laravel Permission

## ⚙️ Requisitos Previos

*   PHP >= 8.5
*   Composer
*   Node.js y NPM
*   MySQL o MariaDB
